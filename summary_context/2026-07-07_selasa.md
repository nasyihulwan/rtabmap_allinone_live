## 3. FIX KRITIS HARI INI — JANGAN DIUBAH

### A) `config/nav2_params.yaml` — `planner_server` ⚠️
```yaml
planner_plugins: ["GridBased", "GridBased_Navfn"]
GridBased:        # nav2_smac_planner/SmacPlanner2D — DEFAULT
GridBased_Navfn:  # nav2_navfn_planner/NavfnPlanner — opsi kedua
```
**Kenapa:** NavfnPlanner (potential-field/grid-8-connected) raw path zigzag parah (turning angle 24.93 rad) — bahkan setelah di-smooth abis-abisan cuma turun ke 9.12 rad. SmacPlanner2D raw (TANPA smoothing) cuma 2.99 rad — smooth "by construction" krn cost-aware A* + penalti belok. Clearance turun sedikit (0.87m vs 1.08m mean) tapi tetap aman.
**JANGAN** ganti balik `GridBased` ke NavfnPlanner tanpa alasan kuat — sudah dites bolak-balik sesi ini, SmacPlanner2D menang telak di kriteria smoothness dgn clearance yg masih aman.

### B) `config/nav2_params.yaml` — `smoother_server`
```yaml
smoother_plugins: ["simple_smoother", "constrained_smoother"]
simple_smoother:
  w_data: 0.2
  w_smooth: 0.6   # naik dari default ~0.3
constrained_smoother:   # opsi kedua, BUKAN DEFAULT — hasil lebih buruk di test
  plugin: "nav2_constrained_smoother/ConstrainedSmoother"
  ...
```
**JANGAN** jadikan `constrained_smoother` default tanpa tuning ulang weight (`w_curve`/`w_smooth`/`w_cost`) — di path serapat (~2.5cm spacing antar titik) hasil optimasi Ceres malah LEBIH ZIGZAG dari raw path (34.71 rad vs 24.93 rad raw).

### C) `config/nav2_params.yaml` — `inflation_layer` (local+global costmap)
```yaml
inflation_radius: 0.50   # dari 0.30 (bug lama, robot_radius=0.38 butuh inscribed radius min 0.382)
```

### D) `config/behavior_trees/navigate_to_pose_w_smoothing.xml` — FILE BARU ⚠️
Custom BT, nyisipin `SmoothPath` di antara `ComputePathToPose` dan `FollowPath`, dibungkus `Fallback` (`SmoothOrKeepRaw`). Default BT Nav2 (`navigate_to_pose_w_replanning_and_recovery.xml`) **TIDAK PERNAH** memanggil smoother sama sekali.
**JANGAN** hapus `Fallback`-nya — tanpa itu, kalau `SmoothPath` collision-abort di titik sempit (pinch point/doorway), seluruh `ComputeAndSmooth` sequence gagal → BT masuk infinite recovery loop, robot gak akan pernah mulai `FollowPath` (pernah kejadian: 12 recovery dalam ~40 detik sebelum fix ini).

### E) `launch/nav2_husky.launch.py` — path BT dihitung dinamis ⚠️
```python
BT_XML_SMOOTHING = os.path.join(
    os.path.dirname(os.path.dirname(os.path.abspath(__file__))),
    'config', 'behavior_trees', 'navigate_to_pose_w_smoothing.xml'
)
# ...
parameters=[PARAMS_FILE, {'default_nav_to_pose_bt_xml': BT_XML_SMOOTHING}],  # override khusus bt_navigator
```
**Kenapa:** sempat hardcode absolute path (`/mnt/ssd/Nasyih_MBKM/...`) langsung di `nav2_params.yaml` — itu BUG karena project ini jalan di 2 mesin beda dgn root path beda (`/mnt/ssd/Nasyih_MBKM/rtabmap_allinone_live/` di anymal-bunny-orin vs `/home/kmp-orin/anas/rtabmap_allinone_live/` di kmp-orin). Sudah difix pakai pola yang sama dengan `PARAMS_FILE` yang sudah ada di file ini (dihitung relatif ke lokasi launch file, bukan hardcode).
**JANGAN** taruh path absolute machine-specific langsung di `nav2_params.yaml` lagi — selalu hitung dinamis di launch file Python.
