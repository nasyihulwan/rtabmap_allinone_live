## 3. FIX KRITIS HARI INI — JANGAN DIUBAH

### A) `config/fastdds_udp.xml` — interfaceWhiteList ⚠️
**Root cause "Did not receive data":**
AP isolation di WiFi → PC Husky (192.168.1.50) tidak bisa reach kmp-orin via WiFi (192.168.0.148) → 100% packet loss. FastDDS tanpa whitelist mengiklankan KEDUA IP ke PC Husky → velodyne data drop → RTABMap tidak terima velodyne → approx_sync tidak pernah firing.

**Fix:** hanya advertise `127.0.0.1` (loopback, intra-machine) + `192.168.1.10` (LAN ke PC Husky).

**JANGAN:**
- Tambah `192.168.0.148` ke whitelist → velodyne mati lagi
- Hapus `127.0.0.1` → relay/static_tf tidak bisa komunikasi antar node di kmp-orin

### B) `/etc/sysctl.d/99-ros2-udp.conf` di kmp-orin — UDP Buffer
```
net.core.rmem_max=33554432
net.core.rmem_default=33554432
net.core.wmem_max=33554432
net.core.wmem_default=33554432
```
Default Linux 208KB terlalu kecil untuk VLP-32C (~1.76MB/scan, 29 UDP fragments). Sudah persistent — tidak perlu set manual setelah reboot.

### C) `run.sh` — Timeout localize
- Timeout 120s → **300s** (5 menit)
- 120s terlalu singkat, robot perlu digerakkan dulu agar loop closure terpicu

### D) `config/nav2_params.yaml` — Nav2 Config Baru (belum ditest)

| Parameter | Lama | Baru | Alasan |
|-----------|------|------|--------|
| `inflation_radius` | 0.5m | **0.30m** | Path terlalu mepet tembok |
| `cost_scaling_factor` | 2.0 | **3.5** | Biaya turun lebih cepat dari obstacle |
| `robot_radius` | 0.4m | **0.38m** | Lebih akurat ke Husky aktual |
| `planner` | NavFnPlanner | **SmacPlanner2D** | Path zigzag → smooth |

| `progress_checker timeout` | 10s | **20s** | Tidak cepat abort |

```

→ Kalau inflation masih terlalu besar: turunkan inflation_radius ke 0.20
   di nav2_params.yaml → restart Nav2
→ Kalau TF tidak ada: cek relay running: ps aux | grep relay
```

**Path masih zigzag**
```
→ Cek SmacPlanner loaded: grep "SmacPlanner" ~/.ros/run_logs/nav2.log
→ Cek smoother: grep "simple_smoother" ~/.ros/run_logs/nav2.log
```

**Velodyne hanya 3Hz (bukan 10Hz)**
```
→ Normal kalau WiFi Husky aktif (data routing via WiFi, lambat)
→ Off-kan WiFi AGX Husky → data full via LAN → ~10Hz
```
